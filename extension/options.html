    How to use
    
    
      
      
    1. Paste an API key above and press Run test. Gemini and Groq both have free tiers; Groq is the fastest, Gemini can also read screenshots.
      2. 
      
    2. Open the game tab and press Alt+Shift+S (or use the toolbar icon) to show the panel.
      3. 
      
    3. When a question is on screen, click ◎ (or Alt+Shift+E) and click the question text. From then on every new question is answered automatically, with no key to press.
      4. 
      
    4. Answers stream in, rarest first. Click one, or press Alt+1…Alt+9, to type it into the game's answer box. Click the game's answer box once at the start so RareSight knows where to type.
      5. 
      
    5. Want other options? Click ↻ More answers (or Alt+0) for a fresh batch, never repeating an answer already shown. Earlier answers stay below as small clickable chips.
      6. 
      
    6. No auto-detect? Select the question text and press Alt+Shift+Q. With nothing selected, it reads a screenshot instead (needs a vision model).
